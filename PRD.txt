이재환 개인 운동 기록 웹앱 종합 기획안
작성일: 2026-09-03
목적: 비개발자가 Claude Code를 활용해 제작할 수 있도록 기능, 화면, 데이터 저장, 설치 소프트웨어, 개발 순서와 예상 일정을 정리한 기준 문서

======================================================================
0. 한 줄 정의
======================================================================

'이재환 프로그램'에서 월요일부터 일요일까지 운동 종목, 순서, 세트 수, 목표 횟수, 중량, 휴식시간을 사용자가 나중에 직접 설정하고, 실제 운동 결과를 날짜별·종목별로 계속 축적하는 개인용 모바일 운동 기록 웹앱을 만든다.

※ 운동 종목과 프로그램 내용은 개발할 때 고정하지 않는다.
※ 앱 완성 후 이재환 사용자가 화면에서 직접 등록하고 수정한다.
※ 첫 버전은 휴대폰에 최적화된 개인용 웹앱이다.
※ 운동 추천, 외부 운동 프로그램 검색 및 커뮤니티 기능은 만들지 않는다.

======================================================================
1. 프로젝트 목표와 범위
======================================================================

1.1 목표
- Boostcamp와 유사한 운동 진행 및 기록 경험을 제공한다.
- 외부의 검증된 프로그램을 검색하거나 선택하는 기능은 제외한다.
- 사용자가 직접 만든 '이재환 프로그램'만 관리한다.
- 월·화·수·목·금·토·일 각각의 운동 계획을 자유롭게 구성한다.
- 세트별 실제 중량과 횟수를 기록한다.
- 같은 운동의 이전 기록과 전체 히스토리를 계속 보관한다.
- 스마트폰 브라우저에서 앱처럼 사용한다.
- 인터넷이 없어도 이미 저장된 데이터로 기본 기록 기능을 사용할 수 있게 한다.
- 데이터 백업 및 복원 기능으로 휴대폰 변경이나 브라우저 데이터 삭제에 대비한다.

1.2 초기 버전에 포함하지 않는 기능
- Boostcamp 프로그램 검색
- 다른 사람이 만든 프로그램 다운로드
- 트레이너 및 커뮤니티 기능
- 사용자 간 공유와 팔로우
- AI 운동 추천
- 식단 관리
- 자동 결제
- Apple Health 및 스마트워치 연동
- 여러 사람의 계정
- 클라우드 자동 동기화

1.3 개발 형태
- 1차: 개인용 모바일 웹앱
- 2차 선택 사항: 서버 저장과 여러 기기 동기화
- 3차 선택 사항: 아이폰 및 안드로이드 설치형 앱

======================================================================
2. 사용 흐름
======================================================================

2.1 최초 사용
1) 웹앱을 연다.
2) '이재환 프로그램'을 만든다.
3) 월요일부터 일요일까지 각 요일을 선택한다.
4) 요일별 운동 종목을 추가한다.
5) 운동 순서, 세트 수, 목표 횟수, 시작 중량, 휴식시간을 설정한다.
6) 설정을 저장한다.

2.2 평상시 운동
1) 웹앱을 연다.
2) 홈 화면에서 오늘 예정 운동을 확인한다.
3) '오늘 운동 시작'을 누른다.
4) 세트별 중량과 횟수를 입력한다.
5) 완료 버튼을 누른다.
6) 휴식 타이머가 자동으로 시작된다.
7) 모든 운동을 마치고 '운동 종료'를 누른다.
8) 수행 결과가 날짜별 및 종목별 히스토리에 저장된다.

2.3 다른 요일 운동
- 실제 요일에 강제로 묶지 않는다.
- 화요일에도 월요일 운동을 수동으로 선택해 시작할 수 있다.
- 미룬 운동, 당겨서 하는 운동, 일정 변경을 지원한다.

4. 프로그램 상세 화면 구성
======================================================================

※ 이 부분은 첨부된 Boostcamp UI에서 확인한 구조를 참고하되, 색상·아이콘·배치와 디자인은 독자적으로 만든다.

4.1 프로그램 상단 영역
- 뒤로가기
- 프로그램명: 이재환 프로그램
- 프로그램 대표 아이콘 또는 사용자 지정 이미지
- 프로그램 설명
- 프로그램 편집 버튼
- 프로그램 복제 버튼
- 적용 시작일
- 최근 수정일

4.2 상단 탭
- 개요
- 운동 일정

4.3 개요 탭
- 프로그램 목적을 사용자 스스로 적는 메모
- 주당 운동 예정 일수
- 주간 총 운동 종목 수
- 주간 총 예정 세트 수
- 현재 사용 중인지 여부
- 프로그램 공통 안내문
- 중량 증가 원칙에 대한 사용자 메모
- 부상 및 주의사항 메모

4.4 운동 일정 탭
- 기본 표시 방식은 월요일부터 일요일까지의 요일 탭이다.
- 가로로 다음 탭을 표시한다.
  [월] [화] [수] [목] [금] [토] [일]
- 선택한 요일의 운동 목록을 카드로 표시한다.
- 각 요일 카드에 종목 수와 총 세트 수를 표시한다.
- 각 요일의 완료 여부와 최근 수행일을 표시한다.
- 모든 운동 펼치기 및 접기 기능을 제공한다.

4.5 요일 카드 내용
- 요일명
- 사용자 지정 운동일 이름, 예: 가슴·삼두
- 운동 종목 수
- 총 예정 세트 수
- 예상 운동시간
- 최근 수행일
- 마지막 완료 여부
- 아래 화살표를 눌러 운동 목록 펼치기
- 해당 요일 운동 시작 버튼

4.6 요일별 운동 목록
각 운동은 다음 내용을 표시한다.
- 운동 순서
- 운동명
- 운동 부위
- 목표 세트 수
- 세트별 목표 횟수
- 설정 중량
- 기본 휴식시간
- 운동별 메모
- 편집 버튼
- 순서 이동
- 삭제 버튼

4.7 화면 하단 고정 버튼
- 선택한 요일에 맞춰 '월요일 운동 시작'처럼 표시한다.
- 실제 오늘 요일과 다르더라도 선택한 요일의 운동을 시작할 수 있다.
- 해당 요일에 운동이 없으면 '운동을 먼저 등록하세요'로 표시한다.

4.8 프로그램 편집 시 가능한 작업
- 프로그램 이름 변경
- 설명 변경
- 운동일 이름 변경
- 요일별 휴식일 지정
- 운동 추가
- 운동 삭제
- 운동 순서 변경
- 세트 수 변경
- 각 세트의 목표 횟수 변경
- 시작 또는 목표 중량 변경
- 중량 증가 단위 설정
- 휴식시간 설정
- 운동별 메모
- 프로그램 복제

- 기구
- 운동 안내
- 주의사항
- 대표 이미지, 선택 사항

5.3 프로그램에 넣을 때 정하는 정보

- 목표 세트 수
- 각 세트의 목표 횟수
- 각 세트의 목표 중량 또는 공통 중량
- 중량 증가 단위
- 기본 휴식시간

- 이미지를 넣을 경우 직접 제작했거나 이용 허가를 받은 이미지만 사용한다.
- 외부 앱의 운동 이미지를 복사하지 않는다.

6. 실제 운동 진행 화면
======================================================================

6.1 상단 고정 영역
- 휴식 타이머 버튼
- 중량 계산기 버튼
- 총 운동량 버튼
- 운동 경과시간
- 운동 종료 버튼

6.2 운동 안내 영역
- 프로그램명
- 선택한 요일
- 운동 시작 시간
- 해당 요일 전체 안내문
- 오늘의 메모 입력

6.3 종목 카드
각 종목을 세로 카드로 표시한다.
- 운동 순번
- 운동명
- 운동 안내 화면 열기
- 휴식 타이머 단축 버튼
- 이전 기록
- 오늘 목표
- 실제 중량 입력
- 실제 횟수 입력
- 완료 체크
- 세트 추가
- 운동 교체
- 더보기

6.4 세트 표의 열
- 세트 번호
- 이전 기록
- 목표 중량 및 목표 횟수
- 실제 중량
- 실제 횟수
- RPE, 선택 사항
- 완료 버튼

6.5 이전 기록
- 같은 운동의 가장 최근 수행 기록을 기본으로 표시한다.
- 각 세트 옆에 최근 중량과 횟수를 표시한다.
- 최근 기록이 없으면 '첫 기록'으로 표시한다.
- 다른 프로그램이나 다른 요일에서 같은 운동을 했더라도 종목 기준으로 최근 기록을 찾을 수 있게 한다.

6.6 세트 완료
1) 중량을 입력한다.
2) 횟수를 입력한다.
3) 완료 체크를 누른다.
4) 세트가 즉시 임시 저장된다.
5) 해당 운동의 휴식 타이머가 자동 시작된다.

6.7 완료 버튼 상태
- 회색: 미완료
- 강조색: 완료
- 경고색: 중량 또는 횟수 누락
- 완료 후 다시 누르면 수정 또는 완료 취소 가능

6.8 운동 중 추가 기능
- 세트 추가
- 추가 세트 삭제
- 오늘만 운동 교체
- 프로그램에도 운동 교체 반영
- 운동 건너뛰기
- 순서 변경
- 당일 중량 일괄 변경
- 준비운동 세트 추가
- 운동별 또는 세트별 메모

6.9 휴식 타이머
- 세트 완료 시 자동 시작
- 운동별 등록된 기본 휴식시간 적용
- 남은 시간 표시
- 일시정지
- 30초 추가
- 건너뛰기
- 종료 시 소리 또는 진동
- 모바일 웹의 잠금화면 알림은 제한될 수 있으므로 첫 버전에서는 앱 화면 내 타이머를 우선 구현한다.

6.10 운동 종료
- 완료 종목 수
- 완료 세트 수
- 미완료 세트 수
- 건너뛴 운동
- 총 운동시간
- 총 운동량
- 메모
- 종료하고 저장
- 계속 운동

6.11 중간 종료 및 복구
- 실수로 브라우저를 닫아도 진행 중 세션을 복구한다.
- 홈 화면에 '진행 중인 운동 이어하기'를 표시한다.
- 사용자가 명시적으로 버리기 전까지 임시 기록을 유지한다.

8. 프로그램 계획과 과거 기록의 분리
======================================================================

8.1 핵심 원칙
- 프로그램은 앞으로 할 운동의 계획이다.
- 운동 세션은 특정 날짜에 실제로 수행한 기록이다.
- 프로그램을 나중에 수정해도 과거 운동 기록은 바뀌면 안 된다.

8.2 저장 방식
- 운동 시작 시 그날의 요일 프로그램을 별도 운동 세션으로 복사한다.
- 이후 원본 프로그램의 세트 수나 중량을 바꿔도 시작된 세션과 과거 기록은 그대로 유지한다.

8.3 예시
- 9월 프로그램: 스쿼트 5세트 × 5회
- 10월 프로그램 수정: 스쿼트 3세트 × 8회
- 9월 히스토리에는 5세트 기록이 그대로 남는다.
- 10월 이후 새 운동에는 3세트 계획이 적용된다.

8.4 프로그램 버전
- 프로그램을 크게 수정할 때 버전을 남긴다.
- 기록에는 당시 사용한 프로그램 버전을 저장한다.
- 사용자는 복잡한 버전 번호를 직접 관리하지 않아도 된다.

9. 중량과 목표 관리
======================================================================

9.1 초기 중량 설정
- 운동을 프로그램에 추가할 때 중량을 직접 입력한다.
- 세트마다 같은 중량 또는 서로 다른 중량을 설정할 수 있다.

9.2 운동 중 변경
- 목표 중량과 실제 수행 중량을 분리한다.
- 당일 컨디션에 따라 실제 중량을 변경할 수 있다.
- 히스토리에는 실제 수행 중량이 저장된다.

9.3 다음 운동 중량
첫 버전:
- 사용자가 직접 다음 목표 중량을 수정한다.

추후 선택 기능:
- 모든 목표 세트 성공 시 지정 중량 증가
- 일부 실패 시 중량 유지
- 연속 실패 시 지정 비율 감소
- 자동 제안 후 사용자가 승인

9.4 단위
- 기본 kg
- 필요하면 lb로 전환
- 중량 증가 단위 예: 0.5kg, 1.25kg, 2.5kg, 5kg

11. 데이터 저장 구조
======================================================================

11.1 첫 버전 저장 방식
- 운동 데이터는 사용자의 스마트폰 브라우저 내부 IndexedDB에 저장한다.
- IndexedDB는 브라우저 안에 구조화된 자료를 보관하는 전자 장부다.
- 프로그램, 운동 세션, 세트 기록처럼 서로 연결된 자료를 저장하기 적합하다.

11.2 저장 대상
[프로그램]
- 프로그램명과 설명
- 프로그램 버전
- 월요일부터 일요일까지의 구성
- 운동 순서
- 세트 수
- 목표 횟수
- 목표 중량
- 휴식시간
- 운동별 메모

[실제 운동 세션]
- 날짜
- 시작 및 종료 시간
- 프로그램과 버전
- 선택한 요일
- 종목 목록
- 세트별 실제 중량과 횟수
- 완료 여부
- RPE
- 추가·삭제·교체 내역
- 메모
- 총 운동시간

[종목 자료]
- 종목명
- 부위
- 기구
- 안내와 주의사항
- 사용자 메모
- 이미지 위치

11.3 데이터 위험
- 브라우저 데이터를 삭제하면 로컬 기록이 사라질 수 있다.
- 휴대폰 분실이나 교체 시 기록이 자동으로 옮겨지지 않는다.
- 따라서 백업과 복원 기능은 첫 버전에 반드시 포함한다.

11.4 백업
- 전체 데이터를 하나의 백업 파일로 다운로드
- 파일명에 백업 날짜 포함
- 백업 전에 포함된 운동 횟수와 최근 기록일 표시

11.5 복원
- 백업 파일 선택
- 파일 검사
- 기존 데이터 덮어쓰기 또는 병합 선택
- 복원 결과와 오류 표시

11.6 추후 서버 저장
필요해질 때 추가:
- 로그인
- 클라우드 자동 백업
- 휴대폰과 PC 동기화
- 새 휴대폰에서 복원
- 이 단계는 첫 버전 확정 후 별도 기획한다.

15. 설치할 소프트웨어와 역할
======================================================================

15.1 Chrome 또는 Edge
- 역할: 제작 중인 웹앱을 실행하고 테스트한다.
- 설치 여부: 이미 설치돼 있으면 추가 설치할 필요가 없다.

15.2 VS Code
- 쉬운 뜻: 프로그램 파일을 보고 정리하는 작업실.
- 설치 여부: 설치 권장.
- 비용: 무료.
- 사용자가 주로 할 일:
  1) 프로젝트 폴더 열기
  2) Claude Code 사용
  3) 실행 결과와 오류 확인

15.3 Node.js LTS
- 쉬운 뜻: 웹앱을 PC에서 실행하는 기본 장치.
- 설치 여부: 필요.
- Node.js를 설치하면 npm도 함께 설치된다.
- npm의 쉬운 뜻: 앱 제작에 필요한 부품을 내려받고 관리하는 도구.
- 최신 Vite 사용 시 호환되는 Node.js 버전을 설치해야 한다.

15.4 Git for Windows
- 쉬운 뜻: 작업 상태를 저장하고 문제가 생기면 이전으로 되돌리는 도구.
- 설치 여부: 필수에 가깝게 권장.
- 기능 하나가 완성될 때마다 저장점을 만든다.

15.5 Claude Code
- 쉬운 뜻: 프로젝트 파일을 분석하고 직접 만들거나 수정하는 AI 작업자.
- 설치 여부: 필요.
- 인터넷과 Claude 계정이 필요하다.
- Windows에서는 Claude Code 공식 설치 방식 또는 Claude Desktop의 Code 기능을 사용할 수 있다.
- 초보자에게는 가능하다면 화면형 Claude Desktop Code가 더 쉬울 수 있다.

15.6 Python
- 설치 여부: 첫 버전에는 불필요.
- 운동 기록, 차트, 타이머, 백업 등은 Node.js 기반 웹앱만으로 개발 가능하다.
- 향후 AI 분석이나 복잡한 서버 계산이 필요할 때 추가한다.

15.7 설치 순서
1) Chrome 확인
2) VS Code 설치
3) Node.js LTS 설치
4) Git for Windows 설치
5) Claude Code 또는 Claude Desktop 설치
6) 모든 프로그램을 닫았다가 다시 실행
7) 설치 상태 확인
8) 프로젝트 폴더 생성

15.8 설치 시 주의
- 공식 사이트에서만 내려받는다.
- 회사 PC가 아닌 개인 PC에 설치한다.
- 설치 과정은 실제 시작할 때 한 단계씩 별도로 안내받는다.
- 임의로 표시되는 광고성 다운로드 버튼을 누르지 않는다.

16. 권장 개발 기술
======================================================================

- React: 화면을 여러 부품으로 나눠 만드는 도구.
- TypeScript: 잘못된 데이터 사용을 미리 발견하도록 돕는 언어.

- IndexedDB: 휴대폰 브라우저 안에 운동 기록을 저장하는 전자 장부.
- PWA: 웹앱을 휴대폰 홈 화면에 추가해 앱처럼 사용하는 방식.
- Git: 작업 이력과 복구.

※ 사용자가 위 기술을 직접 공부한 뒤 코딩할 필요는 없다.
※ Claude Code가 기술 작업을 수행하고 사용자는 요구사항과 실행 결과를 확인한다.

18. 실제 제작 단계와 예상 소요일정
======================================================================

18.1 일정 산정 전제
- 비개발자인 사용자가 Claude Code의 도움을 받아 개인 시간에 제작한다.
- 평일 하루 1~2시간, 주말 3~4시간 정도 작업한다고 가정한다.
- 디자인과 운동 종목 이미지는 단순하게 시작한다.
- 로그인과 클라우드 서버는 제외한다.
- 예상 기간은 오류, 학습 속도, 수정 횟수에 따라 달라진다.

18.2 현실적인 예상
- 기능만 작동하는 시험판: 약 4~6주
- 실제 운동에 안정적으로 사용할 첫 버전: 약 8~12주
- 디자인과 차트까지 다듬은 완성도 높은 개인용 버전: 약 12~16주

18.3 단계별 일정

[준비 단계: 2~3일]
- 소프트웨어 설치
- Claude Code 로그인
- 프로젝트 폴더 생성
- 기본 용어 이해
- 첫 화면 실행

- 데이터 저장 원칙 확정
- 홈, 프로그램, 기록, 설정 메뉴 기본 화면

20. 테스트 기준
======================================================================

20.1 프로그램
- 월요일부터 일요일까지 각각 다른 운동을 저장할 수 있다.
- 휴식일을 저장할 수 있다.
- 운동 순서가 저장된다.
- 세트 수, 횟수, 중량, 휴식시간이 저장된다.

20.2 운동 진행
- 설정한 세트 수가 정확히 표시된다.
- 중량과 횟수를 입력할 수 있다.
- 완료한 세트가 즉시 저장된다.
- 휴식 타이머가 정상 작동한다.
- 브라우저를 닫은 후 진행 상태를 복구한다.

20.3 히스토리
- 같은 종목의 기록이 날짜별로 누적된다.
- 각 날짜의 세트가 빠짐없이 표시된다.
- 프로그램을 수정해도 과거 기록이 변하지 않는다.
- 최고 중량과 총 운동량 계산이 실제 기록과 일치한다.

20.4 백업
- 전체 백업 파일이 생성된다.
- 다른 브라우저 또는 초기화 후 복원할 수 있다.
- 복원 전후 운동 기록 개수가 일치한다.

20.5 모바일
- 작은 화면에서 가로 스크롤이 과도하지 않다.
- 숫자 입력창과 완료 버튼을 한 손으로 누를 수 있다.
- 운동 중 중요한 버튼이 쉽게 보인다.
- 데이터 저장 중 화면이 멈추지 않는다.

21. Claude Code 작업 방식
======================================================================

항상 다음 순서로 진행한다.
1) 이번에 만들 기능 하나를 정한다.
2) Claude Code에 아직 수정하지 말고 계획만 작성하라고 한다.
3) 변경 파일과 테스트 방법을 확인한다.
4) 해당 기능만 구현시킨다.
5) 직접 브라우저와 휴대폰에서 확인한다.
6) 오류를 수정한다.
7) Git으로 정상 상태를 저장한다.
8) WORK_LOG.md에 완료 내용을 남긴다.

계획 요청 예시:
'아직 코드를 수정하지 마. 이재환 프로그램에서 월요일부터 일요일까지 운동을 설정하는 기능의 구현 계획, 변경 파일, 저장 데이터, 테스트 방법을 먼저 설명해줘. 전문용어에는 짧은 뜻을 붙여줘.'

구현 요청 예시:
'승인한 계획대로 요일별 운동 설정 기능만 구현해줘. 운동 내용은 코드에 고정하지 말고 사용자가 화면에서 입력하게 해줘. 작업 후 직접 테스트하고 변경 파일과 결과를 알려줘.'

완료 검증 요청 예시:
'프로그램의 스쿼트를 5세트에서 3세트로 바꾼 뒤에도 과거의 5세트 히스토리가 유지되는지 직접 테스트하고 결과를 보여줘.'
